⑨ Scalable Agent Hub Schema — is_central Attribute NEW FROM PDF
Agent is_central field — three states per city
is_central Value Meaning Constraints Role in Transport
null No central hub has been designated in this city yet. Any number of agents can be null. Transient state during city expansion. Agent operates independently. No hub hierarchy. Marketplace jobs posted/received directly.
true This agent IS the central hub for the city. Unique per city — only ONE agent per city may have is_central = true. Receives inter-city inbound deliveries. Routes batches to sub-agents for last-mile distribution.
false This agent is a sub-agent operating under the central hub. Multiple sub-agents allowed per city. Must have a central hub (is_central=true) in the city. Collects from central hub. Handles last-mile delivery within local zone. May post own marketplace jobs.
City Hub Topology — Visual
CITY A — hub designated

└── distributes to sub-agents
Sub-Agent A1 (is_central = false)

CITY B — no hub designated yet

No hub hierarchy yet. Agents receive/send marketplace jobs independently until a central hub is designated.
